# Компас — правила проєкту

PWA українською мовою: знання й навички, які ШІ не замінить, сенс життя з
християнської перспективи і гайди з ШІ-інструментів. Повне ТЗ — `ПРОМПТ-Компас.md`.

## Стек
- Чистий HTML + CSS + JavaScript. Без бібліотек, фреймворків, збирачів і CDN.
- Звичайні скрипти (не ES-модулі), щоб index.html відкривався і з диска.
- Системний шрифт, іконки — вбудовані SVG.
- Хостинг — GitHub Pages: усі шляхи відносні (`./`), маршрути через hash (`#/lesson/3`).

## Структура
- `data.js` — УВЕСЬ контент. Текст у коді екранів не пишемо.
- `js/storage.js` — `Store`: єдиний, хто звертається до localStorage (ключ `kompas:v1`).
- `js/ui.js` — `UI`: спільні елементи (іконки, заголовки, пункти списку, тост, тема),
  `richText` (формат тексту з data.js), `video` (блок «Відео»), `quiz`/`mountQuiz` (тест),
  `autosave` (автозбереження полів).
- `js/router.js` — `Router` і об'єкт `Screens`.
- `js/screens/*.js` — по файлу на розділ. Кожен файл загорнутий в IIFE і
  реєструє функції у `Screens`. Функція екрана отримує `params` і повертає
  `{ title, html, mount(root) }`; `mount` навішує обробники подій.
- `js/app.js` — запуск: тема, реєстрація маршрутів, старт роутера.
- Порядок скриптів в index.html: data → storage → ui → router → screens → app.

## Правила коду
- Будь-який текст від користувача вставляти в HTML лише через `UI.esc()`.
- Усі звернення до localStorage — тільки через `Store`, з try/catch.
- Нові поля збереження додавати в `defaults()` у storage.js (злиття зі старими даними автоматичне).
- Кольори — лише через CSS-змінні з `:root` / `:root[data-theme="dark"]`.
- Кнопки й посилання — мінімум 44px заввишки. Анімації вимикаються при `prefers-reduced-motion`.
- Коментарі в коді — українською, коротко.

## Контент: НЕ вигадувати
- Посилання на відео: `videoUrl` лишаємо порожнім, заповнюємо тільки `videoQuery`.
- Ціни й ліміти підписок: без цифр, лише загальний опис + `lastChecked` + посилання на офіційний сайт.
- Біблійні вірші — переклад Огієнка, тільки добре відомі місця. Якщо точного тексту
  немає певності — `text: ""` і коментар `// ПЕРЕВІРИТИ`, `ref` заповнити.
- Фінанси і перша допомога — з приміткою «не заміна фахівця».

## Робота
- Працюємо етапами з ТЗ; після кожного — зупинка, звіт «що зроблено / як перевірити / що далі».
- git-репозиторій — ЛИШЕ в цій папці (у домашній теці є інший репозиторій, його не чіпати).
  Коміт після кожного робочого етапу, повідомлення українською.
- Перевірка: локальний сервер (`python -m http.server 8080`), ширина 360px, обидві теми,
  без помилок у консолі, дані зберігаються після перезавантаження.
