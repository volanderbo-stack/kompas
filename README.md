# 🧭 Компас

Мобільний застосунок (PWA) українською: знання й навички, які ШІ не замінить,
мета і сенс життя, гайди з ШІ-інструментів, бібліотека промптів для Claude Code
і трекер проєктів. Працює без інтернету і встановлюється на телефон.

## Як запустити на комп'ютері
Найпростіше — відкрити `index.html` у браузері. Але офлайн-режим і встановлення
працюють лише через сервер. Запустіть у цій папці:

```bash
python -m http.server 8080
```

і відкрийте http://localhost:8080

## Як доповнювати контент
Увесь текст лежить у `data.js`. На початку файлу є інструкція, як додати
роздум, урок, інструмент, промпт чи етап проєкту. Код екранів міняти не потрібно.

**Після будь-яких змін** відкрийте `sw.js` і збільште версію:
`const VERSION = 'kompas-v1';` → `'kompas-v2'`. Інакше на телефоні може
залишитися стара версія з кешу. Додали новий файл — допишіть його у список `FILES`.

## Як викласти на GitHub Pages

### Варіант А — через сайт GitHub (без команд)
1. Зареєструйтеся на [github.com](https://github.com).
2. Натисніть **+** → **New repository**. Назва, наприклад, `kompas`.
   Оберіть **Public** — на безкоштовному плані GitHub Pages працює лише з
   публічними репозиторіями. Натисніть **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file** і перетягніть
   **вміст** папки «Компас» (не саму папку): `index.html`, `styles.css`, `data.js`,
   `manifest.json`, `sw.js`, `README.md` і папки `js` та `icons`.
   Папку `.claude` завантажувати не потрібно. Натисніть **Commit changes**.
4. Відкрийте **Settings** → **Pages**. У пункті **Source** оберіть
   **Deploy from a branch**, гілка **main**, папка **/ (root)** → **Save**.
5. Через 1–3 хвилини застосунок буде за адресою
   `https://ВАШ-ЛОГІН.github.io/kompas/`

### Варіант Б — через git (у цій папці вже є репозиторій з історією)
Створіть порожній репозиторій на GitHub (кроки 1–2, без README), потім:

```bash
git remote add origin https://github.com/ВАШ-ЛОГІН/kompas.git
```

```bash
git push -u origin main
```

і увімкніть Pages (крок 4).

> ⚠️ У комітах записана пошта автора. У публічному репозиторії її побачать усі.
> Якщо не хочете цього, у GitHub → **Settings** → **Emails** увімкніть
> «Keep my email addresses private» і використайте адресу виду
> `…@users.noreply.github.com` (або обирайте варіант А).

### Оновлення
Змінили файли → збільште `VERSION` у `sw.js` → завантажте файли знову
(варіант А) або `git commit` і `git push` (варіант Б). Телефон отримає нову
версію після повторного відкриття застосунку.

## Як встановити на телефон
- **Android (Chrome):** відкрийте адресу → меню ⋮ → «Встановити застосунок»
  або «Додати на головний екран». Також є кнопка в «Налаштуваннях» Компаса.
- **iPhone (Safari):** кнопка «Поділитися» → «На екран „Додому“».

## Резервна копія
Прогрес, цілі, промпти і проєкти зберігаються лише на пристрої. У «Налаштуваннях»
є «Зберегти резервну копію» і «Відновити з файлу» — так дані можна перенести
на інший телефон.
