# 🧭 Компас

Мобільний застосунок (PWA) українською: знання й навички, які ШІ не замінить,
мета і сенс життя, гайди з ШІ-інструментів і бібліотека промптів для Claude Code.

## Як запустити на комп'ютері
Відкрийте `index.html` у браузері. Для офлайн-режиму потрібен локальний сервер.
Запустіть у цій папці:

```bash
python -m http.server 8080
```

і відкрийте http://localhost:8080

## Як доповнювати контент
Увесь текст лежить у `data.js`. На початку файлу є інструкція, як додати
роздум, урок, інструмент чи промпт. Код екранів міняти не потрібно.

## Як викласти на GitHub Pages
Інструкцію додамо на етапі 7.
