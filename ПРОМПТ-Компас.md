# ЗАВДАННЯ: PWA-застосунок «Компас»

## Твоя роль і як працюємо
Ти — досвідчений фронтенд-розробник і редактор навчального контенту.
Я не професійний програміст: пояснюй рішення коротко і простою мовою.

Правила роботи (обов'язкові):
1. Спочатку план, потім код. Працюй ЕТАПАМИ (див. нижче). Після кожного етапу
   зупиняйся, коротко пиши «що зроблено / як перевірити / що далі» і чекай мого «ок».
2. Якщо щось неясно — спитай до початку етапу, не вгадуй.
3. Після кожного робочого етапу — git-коміт з описом українською.
4. На першому етапі створи файл CLAUDE.md з правилами проєкту (стек, структура,
   стиль коду, заборони з цього документа) і дотримуйся його далі.
5. Не додавай бібліотек, фреймворків і збирачів. Чистий HTML + CSS + JS.
6. НЕ ВИГАДУЙ факти, які можуть бути неточними: посилання на відео, ціни
   підписок, ліміти тарифів, тексти біблійних віршів. Правила для них — нижче.

## Суть
Мобільний PWA українською мовою. Мета — допомогти людині:
- залишатися людиною у світі ШІ: мати знання й навички, які ШІ не замінить;
- розуміти мету і сенс життя з християнської перспективи (покликання від Бога,
  праця як служіння, любов до ближнього);
- грамотно і системно використовувати ШІ-інструменти для власних цілей і проєктів.

Тон: теплий, практичний, без моралізаторства і без міжконфесійних суперечок.

## Технічні вимоги
- Файли: index.html, styles.css, app.js, data.js, manifest.json, sw.js, icons/
- Одна сторінка, маршрутизація через hash (#/home, #/sens …) — щоб працювало
  на GitHub Pages без сервера. Усі шляхи — відносні (./).
- PWA: manifest (назва, іконки 192/512 і maskable, theme_color),
  service worker з версією кешу (при зміні версії старий кеш видаляється),
  повна робота офлайн (крім YouTube-відео).
- Жодних зовнішніх CDN і шрифтів — системний шрифтовий стек.
- Mobile-first (від 360px), темна і світла тема + режим «як у системі»,
  перемикач запам'ятовується.
- Великі кнопки (мін. 44px), нижня навігація з 5 вкладок, плавні анімації,
  які вимикаються при prefers-reduced-motion. Базова доступність:
  aria-label на іконках, достатній контраст, фокус із клавіатури.
- Збереження: localStorage, усі звернення обгорнуті в try/catch; застосунок
  не ламається, якщо сховище недоступне.
- У налаштуваннях: «Експорт прогресу» (завантажити JSON) та «Імпорт»
  (відновити з JSON) — щоб дані не загубились при очищенні браузера.
- Кнопка «Копіювати»: navigator.clipboard, а якщо недоступний —
  запасний варіант через виділення тексту. Показувати «Скопійовано ✓».

## Контент — тільки в data.js
Увесь текст (роздуми, уроки, тести, гайди, промпти) — у data.js, щоб я міг
легко доповнювати без зміни коду. На початку data.js — коментар-інструкція
«як додати новий урок / роздум / інструмент». Орієнтовна структура:

```js
const DATA = {
  reflections: [{ id, title, text, verse: { ref, text, translation }, question }],
  lessons: [{ id, topic, title, minutes, body, quiz: [{ q, options, correct }],
              videoUrl: "", videoQuery: "" }],
  tools: [{ id, name, bestFor, subscription, mistakes, prompts: [], tips,
            lastChecked: "", videoUrl: "", videoQuery: "" }],
  toolPicker: [{ task, tool, why }],
  prompts: [{ id, category, title, text }],
  projectSteps: [{ step, description, tool }]
};
```

## Розділи

### Головний екран
- Привітання за часом доби + «Думка дня» (роздум або вірш, змінюється щодня,
  однаковий протягом дня).
- Прогрес: уроків вивчено з N, серія днів поспіль (день зараховується, якщо
  відкрито урок або роздум; пропуск дня обнуляє серію).
- Кнопка «Продовжити, де зупинився» — відкриває останній незавершений урок.

### 1. «Сенс» — мета і сенс життя
- 14+ коротких роздумів: навіщо людина живе, покликання, праця як служіння,
  відповідальність, любов до ближнього, вірність у малому, відпочинок.
- До кожного — вірш із Біблії в перекладі Огієнка, посилання (книга, розділ,
  вірш) і питання для самоперевірки.
- Біблійні вірші: використовуй лише добре відомі місця. Якщо не впевнений
  у точному тексті — залиш поле text порожнім з позначкою «// ПЕРЕВІРИТИ»,
  а ref заповни. Я звірю сам.
- «Моя мета»: поле для життєвої мети + список цілей на рік (додати, відмітити,
  видалити). Зберігається локально.

### 2. «Людина» — знання й навички, які ШІ не замінить
Картки-уроки на 3–5 хв читання, по 2–3 уроки на тему:
- Критичне мислення: перевірка інформації, фейки, помилки й «галюцинації» ШІ
- Фінансова грамотність: бюджет, подушка безпеки, основи інвестування
- Комунікація: говорити, слухати, домовлятися
- Здоров'я: сон, рух, харчування, концентрація без телефону
- Дисципліна і звички: як доводити справи до кінця
- Практичні навички: перша допомога, базовий ремонт, приготування їжі
Після уроку — тест із 3 питань (одразу показувати правильну відповідь і
пояснення) і кнопка «Вивчено». Для фінансів і першої допомоги — помітна
примітка: «Це загальна інформація, не заміна фахівця / курсу першої допомоги».

### 3. «ШІ-інструменти» — гайд під кожен інструмент
Окрема сторінка на кожен: для чого найкращий, що дає підписка порівняно з
безкоштовним планом, типові помилки, 3–5 готових запитів із кнопкою «Копіювати».
- Claude Pro + Claude Code — розробка застосунків, тексти, аналіз
- Gemini (Google AI Pro) — дослідження, Google-сервіси, відео, великі документи
- ChatGPT (безкоштовно) — швидкі питання, друга думка
- NotebookLM — навчання за своїми документами, конспекти, аудіо-огляди
- Perplexity — пошук із джерелами, перевірка фактів
Ціни й ліміти тарифів змінюються часто: НЕ пиши конкретних цифр. Опиши
можливості загально, додай поле lastChecked і рядок «Актуальні умови —
на офіційному сайті» з посиланням на головну сторінку сервісу.
Окремий блок «Який інструмент обрати?» — таблиця «задача → інструмент → чому»
(10–15 рядків), на мобільному — у вигляді карток.

### 4. «Промпти для Claude Code» — бібліотека
- Структура хорошого промпту: мета → контекст → обмеження →
  критерій «готово» → формат результату (з прикладом «погано / добре»).
- Принципи: спочатку план (режим планування), потім код; малі кроки;
  один чат — одна задача (/clear між задачами); просити тестувати
  і пояснювати зміни; правила проєкту в CLAUDE.md (/init); git-коміт після
  кожного робочого кроку; давати скріншот або текст помилки при багах.
- Шаблони з кнопкою «Копіювати»: створити застосунок з нуля, додати функцію,
  виправити баг, покращити дизайн, зробити PWA, викласти на GitHub Pages,
  провести рев'ю коду, написати CLAUDE.md.
- Пошук і фільтр за категорією, позначка «Улюблене» (★), додавання,
  редагування і видалення власних промптів.

### 5. «Системні проєкти» — від ідеї до результату
- Покроковий шаблон: ідея → ТЗ → план → розробка частинами → тестування →
  запуск. На кожному кроці — що зробити і який ШІ-інструмент найкраще підходить
  (напр. ідея — Gemini/Perplexity для дослідження, ТЗ — Claude, код — Claude Code,
  навчання — NotebookLM).
- Трекер проєктів: назва, мета, етап (вибір зі списку), наступний крок, дата.
  Додати / змінити / видалити, сортування за етапом.

## Відео (у кожному уроці та гайді)
- Посилання на YouTube НЕ вигадуй. У data.js поле videoUrl порожнє — його
  заповню я. Поле videoQuery заповни влучним пошуковим запитом українською
  або англійською.
- Якщо videoUrl заповнено — вбудований плеєр youtube-nocookie.com
  (підтримати формати watch?v=, youtu.be/, shorts/), ледаче завантаження,
  пропорції 16:9.
- Якщо порожньо — кнопка «Знайти на YouTube», що відкриває
  https://www.youtube.com/results?search_query=<videoQuery> у новій вкладці.
- Офлайн замість плеєра — напис «Відео доступне з інтернетом».

## Критерій «готово» для кожного етапу
- Відкривається без помилок у консолі на телефоні (360px) і на ПК.
- Обидві теми виглядають акуратно.
- Дані зберігаються після перезавантаження сторінки.
- Після етапу 7: працює офлайн після першого відкриття і встановлюється
  як застосунок на Android.
